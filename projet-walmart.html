Weekly Sales Prediction

Group project developed in an academic context. The objective was to predict weekly sales per store and department using historical Walmart data.

The project covers a complete pipeline: data exploration, data cleaning, feature engineering, modeling, evaluation, and deployment of a user interface.

Machine Learning Python Streamlit GitHub Jira

Résumé du projet

Ce projet vise à construire un modèle capable d’anticiper les ventes hebdomadaires de Walmart. Nous avons travaillé sur plusieurs étapes : analyse exploratoire, traitement des valeurs manquantes, création de nouvelles variables, comparaison de modèles et déploiement d’une application.

Travail réalisé

  • Exploration et analyse des données historiques.
  • Nettoyage des données et traitement des valeurs manquantes.
  • Transformation des variables : variables temporelles, lags, moyennes glissantes et encodage.
  • Construction et comparaison de modèles de Machine Learning.
  • Évaluation avec des métriques adaptées au contexte commercial.
  • Déploiement d’une interface graphique pour tester les prédictions.

Ma contribution

J’ai participé à l’analyse des données, à l’ingénierie des variables, à l’évaluation des modèles et à la préparation de la présentation du projet. Le travail a été organisé avec Git, GitHub et Jira afin de faciliter la collaboration entre les membres de l’équipe.

Project Summary

This project aims to build a model capable of predicting Walmart weekly sales. We worked through several steps: exploratory data analysis, handling missing values, feature engineering, model comparison, and deployment of an application.

Work Done

  • Exploration and analysis of historical data.
  • Data cleaning and handling missing values.
  • Feature engineering: time variables, lags, rolling averages and encoding.
  • Building and comparing Machine Learning models.
  • Evaluation using business-oriented metrics.
  • Deployment of a graphical interface to test predictions.

My Contribution

I contributed to data analysis, feature engineering, model evaluation, and the preparation of the project presentation. The work was organized using Git, GitHub, and Jira to facilitate team collaboration.
